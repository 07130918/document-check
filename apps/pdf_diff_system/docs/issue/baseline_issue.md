問題点：
順序並び替え
ベースライン(PyMuPDFによる文章抽出・位置情報による並び替え）だと文章の崩れが多いために評価が曖昧になる→pdfminer.sixで意味的に分けられる可能性あり
「iOS 11/12/13/14/15/16」vs「11/12/13/14/15/16」のような境界問題→現在は部分一致で対応
差分
完全一致は現在の文章抽出レベルだと機能しない→現在は部分一致で判定を行っている
アノテーションは意味的に区切ってもらっているが，区切り方が難しい→文章単位に変更？
提案：
アノテーションを順序，差分をまとめて一つのファイルにして，文章単位で抜き出し，その中の差分数，差分対象をカラムとする．
