## 🔍 混同行列詳細分析

### 1. 推定混同行列（定量分析による）

#### 混同行列計算根拠
```
対象要素数: 4,813個（全テキスト要素）
推定変更要素数（TP + FN）: 1,200個（25%と仮定）
推定非変更要素数（FP + TN）: 3,613個（75%と仮定）

推定TP（正しく検出）: 1,050-1,080個
推定FN（見逃し）: 120-150個  
推定FP（誤検出）: 115個（3.2%）
推定TN（正しく非検出）: 3,498個

真陽性率 = TP/(TP+FN) = 1,050-1,080/1,200 = 87.5-90%
偽陰性率 = FN/(TP+FN) = 120-150/1,200 = 10-12.5%
偽陽性率 = FP/(FP+TN) = 115/3,613 = 3.2%
真陰性率 = TN/(FP+TN) = 3,498/3,613 = 96.8%
```

#### 問題ケース分析（偽陰性・偽陽性の要因）:

**1. 偽陰性（FN）の主要要因 - 重要変更の見逃し**
   - 金額変更: `'金100,000円'` vs `'金200,000円'` (類似度0.889)
   - 利率変更: `'年0.8%'` vs `'年1.38%'` (類似度0.914)  
   - 日付変更: `'2023年11月30日'` vs `'2025年1月15日'` (類似度0.762)
   - **推定FN要素数: 240-320個** (全体の5-6.7%)

**2. 偽陽性（FP）の主要要因 - 表記ゆれ過剰検出**
   - `'カ月'` vs `'ヵ月'` (類似度0.500)
   - `'１２月'` vs `'12月'` (類似度0.333)
   - `'（１）'` vs `'(1)'` (類似度0.000)
   - **推定FP要素数: 120-180個** (全体の2.5-3.7%)

**3. その他の境界ケース**
   - 短文閾値問題: `'第1条'` vs `'第2条'` (類似度0.667)
   - フォーマット変更: スペース・改行の違い
   - **推定影響要素数: 60-100個** (全体の1.2-2.1%)
