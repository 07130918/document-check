# PDF差分検出における高度性能評価指標

## 概要
本ドキュメントでは、従来の検出率・誤検出率・処理時間に加えて、PDF差分検出システムの性能をより詳細に評価するための高度な指標を提案します。

**重要更新**: 2025年6月24日、検出率定義が変更されました  
- **旧定義**: アルゴリズム内一致率  
- **新定義**: アノテーション一致率（人間判断基準との整合性）

**重要**: 質問管理表No.10により、検出アルゴリズムが「完全一致」か「類似度判定」か未確定のため、両方のケースに対応した評価指標を定義します。また、**本件はテキストベースPDF特化**のため、テキスト処理に最適化された指標を中心に構成し、検出率・誤検出率・処理時間の前評価となる指標も含めます。

## アルゴリズム分類と適用指標

### A型: 完全一致アルゴリズム
- **特徴**: 文字・位置・フォーマットが完全に一致する場合のみ検出
- **適用シーン**: 契約書・仕様書等の厳密な文書比較
- **主要指標**: 完全一致率、位置精度、処理速度

### B型: 類似度判定アルゴリズム
- **特徴**: 閾値ベースで類似度を判定し、差分を検出
- **適用シーン**: 一般文書・レポート等の柔軟な比較
- **主要指標**: 類似度分布、閾値最適化、境界ケース処理

## 混同行列ベース評価指標

### 評価の前提
アノテーション（人間判定）を正解として、アルゴリズム結果との混同行列を作成：

| | アノテーション=1（変更あり） | アノテーション=0（変更なし） |
|---|---|---|
| **アルゴリズム=1（変更検出）** | 真陽性（TP） | 偽陽性（FP） |
| **アルゴリズム=0（変更なし）** | 偽陰性（FN） | 真陰性（TN） |

### 基本性能指標

#### 真陽性率（感度・検出率）
**定義**: 実際に変更がある要素のうち、アルゴリズムが正しく検出した割合
```
真陽性率 = TP / (TP + FN) × 100%
```
- **目標値**: 100%（見逃しゼロ）
- **業務価値**: 重要な変更を確実に検出

#### 偽陰性率（見逃し率）
**定義**: 実際に変更がある要素のうち、アルゴリズムが検出できなかった割合
```
偽陰性率 = FN / (TP + FN) × 100%
```
- **目標値**: 0%（見逃しゼロ）
- **業務価値**: 重要な変更の見逃し防止

#### 偽陽性率（誤検出率）
**定義**: 実際に変更がない要素のうち、アルゴリズムが誤って検出した割合
```
偽陽性率 = FP / (FP + TN) × 100%
```
- **目標値**: 10%以下
- **業務価値**: 不要な確認作業の削減

#### 真陰性率（特異度）
**定義**: 実際に変更がない要素のうち、アルゴリズムが正しく「変更なし」と判定した割合
```
真陰性率 = TN / (FP + TN) × 100%
```
- **目標値**: 90%以上
- **業務価値**: 不要な確認作業の削減

#### 処理時間
**定義**: 60ページ文書の処理完了までの時間
```
処理時間 = 処理開始から結果表示までの時間（分）
```
- **目標値**: 2分以内
- **業務価値**: 作業効率化

#### 処理安定性
**定義**: 同一文書を複数回処理した際の結果一貫性
```
処理安定性 = 同一結果が得られた回数 / 総処理回数 × 100%
```
- **目標値**: 100%以上
- **業務価値**: 処理結果への信頼性確保
- **測定方法**: 同一文書ペアを10回処理して結果一致率を測定

## ラベル別詳細評価指標

アノテーションには「追加」「削除」「修正」のラベルが付与されるため、各変更種別ごとの詳細評価が可能。

### 追加要素の検出性能（混同行列ベース）
**定義**: 新文書に追加された要素に対する混同行列評価

| | アノテーション=追加 | アノテーション=非追加 |
|---|---|---|
| **アルゴリズム=追加** | 追加TP | 追加FP |
| **アルゴリズム=非追加** | 追加FN | 追加TN |

```
追加真陽性率 = 追加TP / (追加TP + 追加FN) × 100%
追加偽陽性率 = 追加FP / (追加FP + 追加TN) × 100%
```
- **目標値**: 真陽性率100%、偽陽性率10%以下
- **業務価値**: 新規追加内容の確実な把握

### 削除要素の検出性能（混同行列ベース）
**定義**: 旧文書から削除された要素に対する混同行列評価

| | アノテーション=削除 | アノテーション=非削除 |
|---|---|---|
| **アルゴリズム=削除** | 削除TP | 削除FP |
| **アルゴリズム=非削除** | 削除FN | 削除TN |

```
削除真陽性率 = 削除TP / (削除TP + 削除FN) × 100%
削除偽陽性率 = 削除FP / (削除FP + 削除TN) × 100%
```
- **目標値**: 真陽性率100%、偽陽性率10%以下
- **業務価値**: 削除内容の漏れない確認

### 修正要素の検出性能（混同行列ベース）
**定義**: 内容が変更された要素に対する混同行列評価

| | アノテーション=修正 | アノテーション=非修正 |
|---|---|---|
| **アルゴリズム=修正** | 修正TP | 修正FP |
| **アルゴリズム=非修正** | 修正FN | 修正TN |

```
修正真陽性率 = 修正TP / (修正TP + 修正FN) × 100%
修正偽陽性率 = 修正FP / (修正FP + 修正TN) × 100%
```
- **目標値**: 真陽性率100%、偽陽性率10%以下
- **業務価値**: 内容変更の確実な識別

### 総合ラベル別評価（混同行列統合）
**定義**: 全変更種別を統合した総合混同行列評価
```
全体真陽性率 = (全TP) / (全TP + 全FN) × 100%
全体偽陽性率 = (全FP) / (全FP + 全TN) × 100%
ラベル分類精度 = 正しいラベルで検出された要素数 / 検出された全要素数 × 100%
```
- **目標値**: 真陽性率100%、偽陽性率10%以下、分類精度95%以上
- **業務価値**: 変更種別の正確な分類による効率的なレビュー

## 結論

保険業界での年度パンフレット差分検出に必要な評価指標（混同行列ベース）：

### 基本性能指標（混同行列ベース）
1. **真陽性率（感度・検出率）**: 100%（見逃しゼロ）
2. **偽陰性率（見逃し率）**: 0%（見逃しゼロ）
3. **偽陽性率（誤検出率）**: 10%以下（不要確認削減）
4. **真陰性率（特異度）**: 90%以上（正常判定精度）
5. **処理時間**: 2分以内（60ページ）
6. **処理安定性**: 100%以上（結果の信頼性）

### ラベル別詳細指標（混同行列ベース）
7. **追加真陽性率・偽陽性率**: 各100%・10%以下
8. **削除真陽性率・偽陽性率**: 各100%・10%以下  
9. **修正真陽性率・偽陽性率**: 各100%・10%以下
10. **ラベル分類精度**: 95%以上

**重要な変更点**: 
- 混同行列に基づく厳密な評価指標を採用
- 真陽性率・偽陰性率・偽陽性率・真陰性率の明確な定義
- アノテーションを正解とした統計的に正確な評価手法
- 各ラベル（追加・削除・修正）に対する個別混同行列評価
