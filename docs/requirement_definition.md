# 🎯 プロジェクトの目的

### ① **業務効率化のため**

- 契約書・仕様書・ガイドラインなど、**類似したPDFを何度も目視で確認していた**
- 毎回の確認作業が「人手・時間」に依存しており、**作業時間とコストがかかっていた**
- 差分の有無を素早く検知できれば、**確認工数を大幅に削減**できる

### ② **ミス防止・品質担保のため**

- 更新されたPDFの内容に微妙な変更があり、**見落としによるトラブルが発生**
- 特に法務・監査・医療・建設など、**一文字の違いが重大な影響を及ぼす業界**
- 差分検出を仕組み化することで、**ヒューマンエラーを防止**し、**リスク回避をしたい**

# ⚙️性能要求の整理

| 項目 | 内容 |
| --- | --- |
| 差分検出＆注釈生成速度 | 約60ページのPDFを1〜2分で処理完了 |
| 対応ファイルサイズ上限 | 最大20MBのPDFを2ファイル同時に処理可能 |
| 操作レスポンス | アップロード・DL・ページ遷移の反応は3秒以内を目標 |
| 同時アクセス対応 | 約3名まで同時利用でも処理性能を維持※重処理集中時はスケーリング検討（システム利用ユーザー数**30~60人**を想定している） |
| 差分検出の精度 | テキストベースPDFを対象とし、単語・行レベルで差分検出＆注釈改行・レイアウトの違いは対象外粒度・精度は今後調整可 |

# ⚠️ リスクの整理と対策

| リスク | 概要・備考 |
| --- | --- |
| 差分検出が想定精度に達しない | 誤検出・過検出の可能性あり。対応：**実際のPDFに注釈を入れて、先方に許容度を確認** |
| PDF形式の多様性による精度のばらつき | 行の順序、フォント違い、改行の違いなどが差分と誤認される |
| 画像ベースPDFの対応不可 | OCR未導入のため、文字抽出が不可能な画像PDFは未対応 |
| セキュリティ要件未定 | 外部クラウド利用や保存の制限有無などが未提示のため、**HTTPS＋一時メモリ保存＋認証付き画面**など、最低限の仮定で構成→ キックオフ時に前提共有・要件すり合わせ |
| UI／注釈レイアウト崩れ | 現時点では対応検討対象外だが、今後フィードバック次第で調整可 |

# 🧠 用語整理

| 用語 | 意味 |
| --- | --- |
| 差分検出 | 2つのPDFの異なる箇所（テキスト）を比較・抽出 |
| 差分出力 | 差分情報を反映した注釈付きPDFの生成処理 |
| 注釈 | ハイライトやコメントなど、差分箇所に付けるマーク |
| OCR / AI-OCR | 画像内の文字を抽出する技術（現時点では未導入） |
| テキストベースPDF | テキストデータとして読み取り可能なPDF（対象） |
| 画像ベースPDF | スキャンなど画像化されたPDF（OCRが必要） |
| 差分の粒度 | 差分を検出する単位（単語／行／段落など） |
| 操作レスポンス | ユーザー操作に対する画面や機能の反応時間 |
| セキュリティ要件 | 通信暗号化・アクセス制御など導入前提となる基準 |
