# PDF差分検出システム アノテーション作業ガイド

## 🎯 プロジェクト概要

**このプロジェクトは何をするものか？**

契約書・仕様書・ガイドラインなど、似た内容のPDFファイルを比較して「どこが変わったか」を自動で見つけるシステムを作るプロジェクトです。現在は人間が目で見て確認していますが、時間がかかり、見落としも発生してしまいます。

**なぜアノテーション作業が必要なのか？**

AIシステムが正しく動くためには「正解データ」が必要です。人間が手作業で「ここが正しい読み順序」「ここが変更箇所」という答えを作ることで、AIが学習できるようになります。

---

## 🔄 2段階アノテーション構成

このプロジェクトでは、2つの段階に分けてアノテーション作業を行います：

### Stage 1: 読み順序アノテーション
**何をするのか**: PDFの文章を人間が読む自然な順番で番号を付ける作業
**なぜ必要か**: PDFの文章は画面上でバラバラに配置されているため、正しい読み順序をAIに教える必要がある
**成果物**: 読み順序が付いたテキストデータ

### Stage 2: 差分検出アノテーション
**何をするのか**: 2つのPDFファイルを比較して、変更された箇所を見つけて記録する作業
**なぜ必要か**: AIが「変更あり/なし」を正しく判断できるようにするための正解データが必要
**成果物**: 変更箇所の判定結果データ

---

## 📊 作業の流れ

```
📄 比較したいPDFファイル2つ（例：[2023年版](https://drive.google.com/open?id=1_gEKt41nRc-UsAyNZuik_b4AxmriAsMb&usp=drive_copy)と[2024年版の保険](https://drive.google.com/open?id=1KxV7AXf6biSEiT2p-OEVcc2JCyfFzOaA&usp=drive_copyパンフレット

    ↓
🔤【Stage 1】読み順序を決める作業
    ├─ 2023年版PDF → 「1.順序id、2.テキスト内容」
    └─ 2024年版PDF → 「1.順序id、2.テキスト内容」
    ↓
🔍【Stage 2】差分を見つける作業
    └─ 2023年版 vs 2024年版 → 「3行目の日付が変更されている」
    ↓
✅ 完成：AIが学習できる正解データ
```

**重要なポイント**: Stage 1が終わってからStage 2を行います。順序を守って作業してください。

## 🎯 作業の品質目標（どのくらい正確に作業する必要があるか）

### Stage 1: 読み順序アノテーション
| 何を測るか | 目標 | 意味 |
|-----------|------|------|
| **作業者同士の一致率** | 95%以上 | 2人が同じ文書を作業した時、95%以上同じ順序になる |
| **作業完了率** | 100% | すべての文章に順序番号を付ける |

### Stage 2: 差分検出アノテーション
| 何を測るか | 目標 | 意味 |
|-----------|------|------|
| **作業者同士の一致率** | 95%以上 | 2人が同じ文書を作業した時、95%以上同じ判定になる |
| **変更の見逃し率** | 0% | 変更があるのに「変更なし」と判定してはいけない |

## 👥 作業体制

### Stage 1: 読み順序アノテーション
- **1次作業者**: 最初に読み順序を決める人
- **2次作業者**: 1次作業者の結果をチェックして修正する人

### Stage 2: 差分検出アノテーション
- **1次作業者**: 最初に差分を見つける人
- **2次作業者**: 1次作業者の結果をチェックして修正する人

## 🚀 初めて作業する方への手順ガイド

### Step 1. 準備
1. **作業マニュアル**を読む（Stage 1なら`1.reading_order_annotation_manual.md`）

### Step 2: 作業開始
1. **進捗管理シート**に自分の名前と担当ファイルを記録
2. **テンプレート**をコピーして作業用ファイルを作成
3. **マニュアルに従って作業**を実施

### Step 3: 品質チェック
1. **自分で一度見直し**をする
2. **2次作業者**にレビュー依頼
3. **修正があれば対応**して完了

### Step 4: 完了報告
1. **CSV形式で保存**
2. **進捗管理シート**で完了報告
3. **次の作業**があれば継続
