# PDF差分検出アノテーション作業マニュアル (Stage2)

## 📋 概要

- **目的**: 差分検出システムの性能評価用正解データ作成
- **対象**: 前年度・今年度文書間での意味的差分
- **評価基準**: 変更あり/なしの判定精度による品質確保

---

## 🎯 アノテーション目標

### 品質目標
- **アノテーター間一致率**: 95%以上（単純一致率）
- **分類精度**: 100%（変更タイプ分類の正確性）
- **変更の見逃し率**: 0%

### 前提条件
- **文書データ準備**: 前年度・今年度の対象文書が準備されていること
- **対応関係明確化**: 比較対象となる文書ペアが明確であること

## 📊 アノテーション記録ファイル仕様

### ファイル命名規則
```
annotation_{文書名}_年{(古)}and{年(新)}
```

### 例
- `annotation_insurance_pamphlet_2023and2024`

### 列定義

| 列名 | 必須 | データ型 | 説明 | 入力例 |
|------|------|----------|------|--------|
| **要素ID** | ✅ | テキスト | 一意識別子 | 00001, 00002... |
| **前年ページ数** | ✅ | 数値 | 前年度文書のページ番号 | 1, 2, 3... |
| **前年テキスト** | ✅ | テキスト | 前年度の文章内容 | 令和6年6月30日 |
| **後年ページ数** | ✅ | 数値 | 今年度文書のページ番号 | 1, 2, 3... |
| **後年テキスト** | ✅ | テキスト | 今年度の文章内容 | 令和7年6月29日 |
| **変更タイプ** | ✅ | プルダウン | 変更の種類 | 追加, 削除, 修正 |
| **変更詳細** | ✅ | プルダウン | 具体的な変更内容 | 日付変更など |
| **備考** | ❌ | テキスト | 特記事項 | 判定困難な理由等 |

## 📏 差分判定ルール

### 基本ルール

#### 1. **文字単位での変更検出**
- テキスト・数字・記号・スペースを含む1文字単位の違いがあれば変更ありと判定
- 大文字・小文字の違いも変更ありと判定

#### 2. **変更タイプの分類**
- **追加**: 新しい内容の追加
- **削除**: 既存内容の削除
- **修正**: 既存内容の変更

### 判定対象

#### **変更ありケース**
- 1文字以上の違いがある全てのケース
- 文字の追加・削除・置き換え
- 数字・記号・スペースの変更
- 大文字・小文字の違い
- ひらがな・カタカナの違い

#### **変更なしケース**
- 文字列が完全に一致する場合のみ

## 👥 品質管理体制

### ダブルチェック体制
1. **一次アノテーター**: 差分判定の初回実施
2. **二次アノテーター**: 差分判定の検証・修正

### 品質評価方法

#### **アノテーター間一致率**
- 計算式: 一致した判定数 / 全判定数 × 100%
- 目標: 95%以上
