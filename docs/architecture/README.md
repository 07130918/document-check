## 図表の見方

### Mermaid図
このドキュメントではMermaid記法を使用して図を作成しています。
- GitHub上では自動的にレンダリングされます
- VS Codeでは拡張機能でプレビュー可能です
- その他のツールではMermaid対応のビューアーが必要です

### アーキテクチャ図の記号
- `[ ]` : コンポーネント/サービス
- `( )` : データストア
- `-->` : データフロー
- `-.->` : 非同期/オプショナルなフロー
- `subgraph` : 論理的なグループ
