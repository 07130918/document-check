# PDF差分検出システム - インフラストラクチャ設計書

## 1. インフラストラクチャ概要

### 1.1 設計方針
- **クラウドネイティブ**: Azure PaaSサービスを最大限活用
- **Infrastructure as Code**: Terraformによる構成管理
- **高可用性**: 99.5% SLAの実現
- **セキュリティファースト**: ゼロトラストモデル採用
- **コスト最適化**: 自動スケーリングとリソース管理

### 1.2 主要コンポーネント

```
┌─────────────────────────────────────────────────────┐
│                   利用者（30-60人）                   │
```

## 5. 外部API連携設計

### 5.1 OpenAI API 連携

#### 接続設定
```yaml
API エンドポイント: https://api.openai.com/v1/
認証方式: Bearer Token (API Key)
使用モデル: gpt-4-turbo (暫定)
用途: PDF読み順序推定
```

#### セキュリティ考慮事項
- API Keyは Azure Key Vault で管理
- 送信データは最小限に限定（テキスト抽出結果のみ）
- レート制限対応（429エラーハンドリング）
- タイムアウト設定: 30秒

#### コスト管理
- 月間使用量上限設定
- 使用量監視とアラート
- キャッシュ機能による API 呼び出し削減
